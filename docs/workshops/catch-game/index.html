BUILD SOMETHING YOU CAN PLAY

Catch the apples

Move a bowl with the arrow keys. Catch falling apples, hear a sound, and earn one point for every catch.

Level: Creator — you will learn your first score variable. The movement and catching stages use Builder concepts. Ages: 8–15 · Time: about 65 minutes, plus an optional 10-minute warm-up. Split into two sessions after Fall and try again if you like. Younger learners may enjoy working with a coding buddy.

Before you start

Use Scratch 3 on a computer with arrow keys. No account is needed. Be ready to select a sprite, join blocks, start a script with the flag, and try a motion block. The first page includes a short readiness check and warm-up. You do not need to know loops, conditions, coordinates, or variables yet.

What you will learn

  • Hold arrow keys to move a bowl in either direction.
  • Use a loop and coordinates to make an apple fall repeatedly.
  • Detect a catch, add one point, and reset the game with the flag.
