SCRATCH 3 · Catch the apples

Play, test, and save

You made a game with controls, falling objects, catches, and points.

Predict

What should happen if you click the green flag after scoring five points?

Build

  1. Run the play checklist below.
  2. Fix one problem at a time using the earlier pages.
  3. Use File → Save to your computer to save your finished .sb3 file.
  4. Stop the game, then use File → Load from your computer to reopen the saved copy.
  5. Click the flag and play again. You can show someone on your device without publishing or making an account.

Check it works

TestSuccess looks like
Start and restartBowl is at x 0, y −130; Score is 0; Apple starts at y 180.
Hold right, then leftBowl follows the chosen arrow.
Release both arrowsBowl stops moving.
Miss three applesEach returns to the top; none adds points or catch sounds.
Catch five applesEach adds exactly one point and returns to the top.
Restart during a fallThe game resets and continues with one falling Apple.
Open the saved fileThe same scripts, sprites, and sound are present.

The core game runs until you press Scratch’s red stop button. There is no timer, life counter, or win screen in this workshop.

If something goes wrong

What you seeWhat to checkTry this

Reopened game is an older versionYou may have opened an earlier downloadSave a new file and check its name and date.

Why it works

A complete game needs a clear starting state as well as rules during play. Without looking, name the block that repeats, the block that asks a question, and the variable that remembers points.

Want to explore more? Memory match is an existing Coderling Creator workshop with lists, clones, and messages. It is a larger next project, not a prerequisite. Revisit its setup warm-up before beginning.

Source: How to Make a Catch Game in Scratch | Tutorial by Scratch Team, presented by Zoë (Zinnea). Coderling adds checkpoints, explicit resets, and consolidated scripts.
