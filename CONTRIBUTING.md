# Contributing to Coderling

Contributions that make the workshops clearer, safer, or easier to follow are welcome. Open an issue before proposing a substantial change so its scope can be discussed.

By submitting a pull request or other contribution, you confirm that you have the right to submit the material and agree to the contribution terms in the [license](LICENSE). Do not include third-party text, images, code, or other material unless its license permits the proposed use and you document its source.

Keep changes focused, preserve source attribution, and run the project checks before submitting:

```sh
hugo --minify --panicOnWarning
python3 scripts/check_site.py
```
