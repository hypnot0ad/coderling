Make something. Test an idea. Make it your own.

Coderling helps curious kids learn to code by building games and interactive projects in Scratch. Our workshops are designed for ages **8–15**, with clear steps, time to experiment, and checkpoints that help you see your progress. Work at your own pace, with a coding buddy or an adult when you want a hand.

[Browse all workshops →](workshops/)

## Our objectives

- **Build confidence.** Turn a small idea into something you can play and explain.
- **Think like a coder.** Break problems into steps, predict what will happen, and test your ideas.
- **Learn through debugging.** Notice what happened, change one thing, and try again.
- **Be creative.** Change the theme, invent a rule, and make a project that feels like yours.
- **Understand the code.** Discover why the blocks work together, rather than just copying them.

Each workshop follows a familiar rhythm: predict, build, check, and reflect. Save your project at each checkpoint. There is no race to finish.

## Choose your level

Levels describe the concepts in a project. They are not age groups or scores, and you do not need to complete every level in order. Read a workshop’s readiness check to find your starting point.

| Level | What to be ready for | What you will explore |
|---|---|---|
| **Starter** | No coding experience needed. Be ready to click, drag, and try things. | The Scratch editor, sprites, events, and short sequences that move or animate a character. |
| **Builder** | Select a sprite, join a short script, and start it with an event. | Loops, coordinates, sensing, and conditions that react to keys or other objects. |
| **Creator** | Follow and test a short script. Check the workshop’s prerequisites; some introduce advanced ideas for the first time. | Variables that remember values, or larger ideas such as messages, clones, lists, and custom blocks. Each workshop explains which ones it uses. |

**A first score variable counts as Creator.** Catch the apples introduces that idea gently; Memory match combines several Creator concepts in a longer project. A workshop can teach a concept you have never used before, as long as its prerequisites are covered.

## What is Scratch?

[Scratch](https://www.scratchfoundation.org/home) is a free programming tool and online community where you can make games, animations, and interactive stories. You snap colourful blocks together to tell characters, called **sprites**, what to do.

Coderling uses **Scratch 3**. You can follow these workshops in the [Scratch editor](https://scratch.mit.edu/projects/editor/) and save `.sb3` project files on your computer without an account. Catch the apples uses a keyboard with arrow keys; Memory match uses clicks. You can also use the [Scratch app](https://scratch.mit.edu/download) for offline coding.

## Pick your first project

### Catch the apples

Move a bowl, catch falling apples, and keep score. Learn controls, loops, conditions, and your first variable.

**Creator · ages 8–15 · about 65 minutes**

Includes a readiness warm-up. A good first choice if you are new to Coderling.

[Start Catch the apples →](workshops/catch-game/)

### Memory match

Turn over cards, find pairs, and build a shuffled memory game with lists, clones, and messages.

**Creator · ages 8–15 · about 100 minutes**

A longer project with more moving parts. Try it in two sessions if you like.

[Start Memory match →](workshops/memory-match/)
